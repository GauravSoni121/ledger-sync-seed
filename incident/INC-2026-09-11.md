# INC-2026-09-11

Root cause: Amounts.first() used a regex that only matched rupee amounts with two decimal places, so integer amounts such as Rs.5 were skipped and the following stated balance was extracted as the transaction amount.

Reproduction: The HDFC SMS Rs.5 debited ... UPI/WATER CAN. Avl Bal: Rs.92,213.10 was parsed as a ₹92,213.10 debit instead of ₹5.00.

Blast radius: The old parser behavior matched this failure pattern in 21 messages in ixtures/corpus-a.jsonl.

Fix: Updated the transaction amount regex to accept integer and decimal rupee amounts, and added a regression test covering the incident message.

Verification: The regression test failed before the fix and passed after it; the full Gradle test suite is now green.
