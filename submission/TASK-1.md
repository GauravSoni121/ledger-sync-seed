# Task 1 — Track Teardown

## Objective

I reviewed the Track/transaction experience with a focus on usability, clarity and trust.

## What I Checked

I looked at the transaction flow and focused on:

- Transaction amount
- Transaction date
- Merchant/description
- Account/source information
- Data synchronization
- How easily a user can understand a transaction

## What Builds Trust

### Transaction amount

The amount is one of the most important pieces of information because users need to immediately understand how much money was involved.

### Transaction date

Showing the transaction date clearly helps users connect the transaction with their actual activity.

### Merchant/description

The merchant or transaction description helps the user understand what the payment was for.

### Account/source

The source of the transaction is important because users should know which account or data source the transaction came from.

### Sync status

A visible sync status would help users understand whether the information shown is current.

## Areas That Could Be Improved

### 1. Transaction source visibility

The source/account information should be easy to find without requiring the user to investigate.

### 2. Sync visibility

The product could make the last successful sync and current sync state more prominent.

### 3. Incorrect transaction reporting

There should be a simple way for a user to report an incorrect or unexpected transaction.

## Three Product Suggestions

### 1. Show transaction source

Display the originating account/data source clearly with the transaction.

### 2. Add "Report incorrect transaction"

Give users a simple action to report incorrect data.

### 3. Add sync health information

Show:

- Current sync status
- Last successful sync
- Failed sync status
- Retry option when appropriate

## Trust Model

For a financial-data product, I think a user should be able to answer these questions quickly:

1. Where did this transaction come from?
2. When did it happen?
3. What amount was involved?
4. Which account does it belong to?
5. Is the data up to date?
6. What can I do if something looks wrong?

## Final Observation

The Track experience should not only show financial information but also make the information easy to verify. Clear source information, visible sync status and an easy correction/reporting mechanism would make the experience more transparent for users.
