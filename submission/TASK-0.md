# Task 0 — Simplify Money Product Feedback

## Product Experience

I used the Simplify Money app and went through the main user flow. Overall, I found the idea useful because financial transactions can be viewed in one place instead of checking different sources separately.

The main thing I focused on was whether the information was easy to understand and whether I could trust the transaction details.

## Referral and Feedback

I referred the product to three people and collected their feedback.

### Feedback 1

The first person found the overall idea useful and liked having financial information available in one place. The main concern was that some transaction details could be clearer, especially where a transaction came from.

### Feedback 2

The second person found the interface reasonably simple to understand. They felt that the sync status should be more visible so that a user knows whether the latest data has been updated.

### Feedback 3

The third person liked the transaction-viewing experience. They suggested having an easier way to report or correct a transaction if any information looks incorrect.

## Common Themes

The common points from the feedback were:

1. Users liked having financial information in one place.
2. Transaction source/details should be more visible.
3. Sync status should be easier to understand.
4. Users should have a simple way to report incorrect information.

## Three Product Improvements

### 1. Clear transaction source

Show the account/data source clearly with each transaction.

**Why:** Users can understand where the transaction came from and feel more confident about the data.

### 2. Report incorrect transaction

Provide a simple option to report an incorrect transaction.

**Why:** Users need a direct way to flag information that does not look correct.

### 3. Clear sync status

Show the last successful sync time and the current sync state.

**Why:** Users can easily understand whether their financial information is up to date.

## Final Observation

The main learning for me was that financial products need to make data understandable as well as available. Small things like transaction source, sync status and correction options can make the experience more transparent and trustworthy.
